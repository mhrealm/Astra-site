## 🧐如何实现一个迷你版的 reactive ？

众所周知 reactive 的实现的底色是的 proxy，所以实现 reactive 之前需要先了解 proxy，下面是关于 proxy 的简介。

Proxy 就是 JS 对象外面的一层“拦截器”，代理的本质是对象，这也是和 vue2 中的 Object.defineProperty()的本质区别，主要有如下的代理能力。

- 读取属性：get
- 设置属性：set
- 删除属性：deleteProperty
- 判断属性是否存在：has
- 遍历属性：ownKeys

而这一次主要介绍的能力就只有两个get和set。

```js
const state = new Proxy(
  { count: 0 },
  {
    get() {
      // 读取时收集依赖
    },
    set() {
      // 修改时触发更新
    },
  },
)
```
